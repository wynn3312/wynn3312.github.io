# 김경수

게임 시스템과 콘텐츠를 설계하고 운영해 온 기획자입니다.
현재는 LLM과 자동화를 기획과 업무에 적용하는 여러 시도를 이어가고 있습니다.

## 경력과 교육

### 경력

- 플러그박스 · 게임 기획 · 2025.11 ~ 2025.12 (1개월)
- 레포르게임즈 · STUDIO S.E.T / 기획 매니저 · 2024.07 ~ 2025.10 (1년 3개월)
- 와이어게임즈 · 게임 시스템 기획 · 2023.04 ~ 2024.07 (1년 3개월)
- 스튜디오8 · 사업기획실 / 기획팀 리드 · 2016.05 ~ 2023.03 (6년 10개월)

### 교육

- 플레이데이터평생교육원 · SK네트웍스 Family AI 캠프 과정 참여 (960시간)
- 서울게임아트학원 · 게임QA운영 기획전문가 과정 정상수료 (360시간)

## 현재 집중하는 분야

- 게임 및 인터랙티브 콘텐츠 기획
- LLM·에이전트 활용과 업무 자동화
- 프로젝트 문서화와 지식 구조화

## 이 블로그에서 다루는 내용

- AI를 활용한 설계·구현과 반복 업무 자동화 과정
- 실제 직무에서 운영한 게임 프로젝트와 담당 업무를 정리한 경력 포트폴리오
- 별도로 진행한 작업 중 공개할 만한 결과를 선별한 프로젝트 포트폴리오
- 최신 기술 중 관심 있는 주제의 조사와 정리
- 자주 사용하는 도구로 개발 환경을 빠르게 구축하고, 필요한 설정을 다시 활용할 수 있도록 정리한 내용
- 개인적으로 관심 있는 주제를 Lab에서 먼저 실험하고 결과를 기록하며, 유의미한 결과는 재사용할 수 있는 형태로 정리하거나 Portfolio로 이관한 내용
- 실험과 조사 과정에서 참고한 외부 링크와 핵심 내용
