# 김경수

게임 개발 경험을 바탕으로 AI·추천 시스템·에이전트 기반 서비스를 만들고 있습니다.

## 현재 집중하는 분야

- 게임 및 인터랙티브 콘텐츠 개발
- LLM·에이전트 기반 서비스 설계
- 추천 시스템과 데이터 전처리
- 프로젝트 문서화와 지식 구조화

## 대표 프로젝트

- 냉장고 재료 기반 레시피 추천 서비스
- 프로젝트 문서·히스토리 지식베이스

## 이 블로그에서 다루는 내용

- 프로젝트 설계부터 구현·평가·회고까지의 과정
- 새로 익힌 기술과 재사용 가능한 해결 방법
- 논문·도구·서비스를 직접 검토한 기록
- 포트폴리오와 경력 정리 과정
