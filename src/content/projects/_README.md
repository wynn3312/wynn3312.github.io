# Portfolio 콘텐츠 작성법

이 파일은 이름이 밑줄로 시작하므로 사이트에 노출되지 않습니다.

- 포트폴리오 하나당 Markdown 또는 MDX 파일 하나를 만듭니다.
- 하나의 게임이나 프로젝트 전체를 넓게 설명하기보다, 그 안에서 직접 담당한 영역이 제목과 요약에 드러나도록 작성합니다.
- `role`에는 당시 역할이나 직책을 기록합니다.
- 본문은 `게임·프로젝트 소개 → 참여 배경과 기간 → 내 역할 → 담당 업무 → 문제 해결 → 결과와 배운 점` 순서를 기본으로 합니다.
- 공동 작업과 본인의 기여를 명확히 구분하고, 공개할 수 없는 내부 정보·수치·자료는 일반화하거나 제외합니다.
- 작은 작업과 실험은 먼저 Lab에 기록하고, 공개 가치와 완성도가 충분해지면 Portfolio로 이관합니다.
- 더 긴 설명이나 세부 근거는 하위 문서로 분리해 연결할 수 있습니다.
